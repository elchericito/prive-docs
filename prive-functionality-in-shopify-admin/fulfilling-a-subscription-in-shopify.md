# 🛒 Fulfilling a subscription in Shopify

{% hint style="info" %}
All order fulfillment should be handled in Shopify. Prive does not offer any order fulfillment configuration in the app because Prive leverages Shopify payments. Once the order has gone through to Shopify payments all order fulfillment will occur in Shopify.
{% endhint %}

## Fulfilling a subscription order in Shopify

1. Navigate to the “orders” tab of your Shopify storefront.
2. Select the correct order or customer.
3. Select the “Fulfill item” button in the middle of the page.
