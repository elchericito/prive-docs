# 💳 Refunding a subscription in Shopify

{% hint style="info" %}
All refunds should be handled in Shopify. Recurly Commerce does not offer any refund configuration in the app because Recurly Commerce leverages Shopify checkout. Once the order has gone through to Shopify payments all order refunds will occur in Shopify.
{% endhint %}

There are 2 flows that you can use to find a subscription order that needs to be refunded.

### Refund Flow #1

1. Navigate to the “orders” tab of your Shopify storefront.
2. Select the correct order or customer
3. Select “Refund” at the top right hand corner of the page.

### Refund Flow #2

1. Navigate to the “Customers” tab of the Recurly Commerce app.
2. Search for the customer by name or email who needs to have their order refunded.
3. Scroll down to the “order history” section of the subscription contract.
4. Select the purple highlighted link of the order that needs to be refunded.
5. The Shopify orders page will appear for the customer and you can select “Refund” at the top right hand corner of the page.
