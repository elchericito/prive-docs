# 💰 Discount Codes

{% hint style="info" %}
AtRecurly Commerce, our system reads in only existing Shopify discount codes that can be input into existing subscription contracts. Our system does not create discount codes inRecurly Commerce, unlike other legacy providers. All discount codes should be created in Shopify.&#x20;
{% endhint %}

### Creating a Discount Code in Shopify

1. To create a discount code for subscribers, navigate to the “discounts” section of the Shopify storefront and select the green “create discount” button in the top right hand corner.

<figure><img src="../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>

2. Next, select the “Amount off order” discount type, the method, and the percentage or fixed amount off to have the discount apply to an existing subscription order.

![](<../.gitbook/assets/image (6).png>)

Note: When generating a name for a discount code be sure to exclude all special characters such as (%,$,& etc.)&#x20;

3. In the value section under “purchase type” select “Subscription” or “Both” to insure the discount code will be available for subscribers. Complete the other discount fields as necessary and select “save” at the bottom of the page.

<figure><img src="../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure>

### Adding Discount Code to Subscription

4. Lastly, navigate to the “customers” tab, to find the customer contract the discount code should be applied to. In the contract, select the button labeled “Coupon Code” and enter the discount code.

The coupon code will apply based on the parameters previously configured during the creation of the discount in Shopify.

![](<../.gitbook/assets/image (1).png>)

![](<../.gitbook/assets/image (44).png>)

The coupon code can be applied during the first subscription purchase checkout flow, or by a subscriber in their customer portal to their existing subscription contract, or in the “Customers” tab of the Recurly Commerceapp by a merchant managing a customer’s subscription contract.
